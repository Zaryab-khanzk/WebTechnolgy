Faculty Login

Password policy has been updated!
Please review the new requirements before logging in.
  • Password must have a minimum length of 8 characters.
  • Password must contain at least one digit (0-9).
  • Password must contain at least one uppercase letter (A-Z).
  • Password must contain at least one lowercase letter (a-z).
  • Password must contain at least one special symbol, like !@#$%^&*()_+=[]{};:< >|./?,-.
  • Do not use password containing your Name,same SEQUENCE of characters,COMSAT,COMSATS,CUI,CIIT,Admin,abc. e.g; (Admin@123,cui@123 )
  • Passwords must be changed within 60-90 days. Passwords will expire after 60-90 days.

For example, "Coms@ts1" meets these criteria. Please do not use the example password provided above. Take care when changing your password, and make sure to remember the new one.
